# docs/ui

Planning and reference docs for implementing the screens from the Claude
Design project (`Moneta.dc.html`), kept separate from the actual component
code.

- `implementation-plan.md` — screen-by-screen breakdown, build order, and
  the design ↔ code sync workflow. Start here before implementing any screen.
- `design-tokens.md` — rationale for the design tokens in
  `src/styles/index.css` (the tokens themselves live in code, not here).
