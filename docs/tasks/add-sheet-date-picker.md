# Add sheet — the date picker

The date chip opens a calendar floating above the sheet, built on
`react-day-picker` behind a Radix popover, both rethemed onto the project's
tokens. It replaced a hand-written grid that rendered in normal flow, always
padded to six week rows, and sized its day cells under the 44px touch floor.

Rules and implementation: `specs.md` §10.50.
